# Bundled saver texts: notices and credits

`hooks/savers.ts` (`BUNDLED`) carries the SKILL.md bodies of four MIT-licensed plugins, frontmatter stripped. The company leader uses a copy only when the installed plugin's file cannot be read. Each copy is unchanged, except that headroom's `${CLAUDE_SKILL_DIR}` reads `the headroom skill folder`. The full license of each plugin follows.

| Saver | Version | Author | Source |
|---|---|---|---|
| caveman | 1.1.2 | Ali Akram | https://github.com/akramsystems/caveman |
| headroom | 1.3.2 | Stefan Petrovici | https://github.com/petrovicistefan/claude-code-plugins |
| ponytail | 5.3.3 | Dietrich Gebert | https://github.com/DietrichGebert/ponytail |
| i-have-adhd | 0.4.1 | Ayoub G. | https://github.com/ayghri/i-have-adhd |
