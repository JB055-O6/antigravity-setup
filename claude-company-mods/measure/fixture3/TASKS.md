# Fixture 3 tasks

Rules for the runner (Task 4):

- Work copy: each run gets a new empty directory `$W`. Fixture tasks: `python3 -I gen.py $W` (T3: `python3 -I gen.py $W --fixed`, so its tests start green). T1-big: `git -C <repo> archive 4b40414 | tar -x -C $W`, then `git -C $W init -q -b main && git -C $W add -A && git -C $W commit -q -m snapshot` with a fixed author, so the graph module sees a git repo. Never reuse a work copy.
- The session runs with cwd `$W`. The prompt is the prompt cell, sent exactly as written.
- `regex` rule: every backticked pattern must match the final answer (the `result` text of the stream-json `result` event) with Python `re.search`. Patterns use only inline flags.
- `cmd` rule: after the session ends, run the backticked command with bash, cwd `$W`, env `FIXTURE` = the absolute path of this directory. Exit 0 = pass. The command copies the held-out tests from `grading/` into the work copy, so the session never sees them.
- Every fixture task (all but T1-big) also fails when `python3 -I "$FIXTURE/grading/grade.py" hashes` exits non-zero after the session: a file under `tests/` or `logs/app.log` changed.
- T6: the scorer also logs whether the session made an Agent call (from the jsonl). This is logged, not graded.
- T1-big runs only for setups C, E and F (spec section 15).
- `python3 -I test_gen.py` checks every rule below: a correct answer built from the generated files passes, and near-miss answers fail.
